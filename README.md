# Nom du projet

l'application permet de créer des taches de les modifier et de les supprimer.

## Fonctionnalités
- Modifier
- Supprimer
- Ajouter


## Technologies
- Python, Django, Tailwind CSS (CDN)

## Installation
```bash
git clone https://github.com/diarissoCoder/todo_django.git
cd todo_django
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
## Lancer les tests
python manage.py test
